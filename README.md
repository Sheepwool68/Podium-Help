# Podium Help

Help for **Podium**, race timing software by RFID Timing.

These pages are free to read and free to use. They are written so that an AI assistant can read
them and answer your questions from them.

## Using them with your own AI

Give your assistant this address and ask it your question:

```
https://raw.githubusercontent.com/Sheepwool68/Podium-Help/main/index.md
```

It works with any assistant that can read a web page — Claude, ChatGPT, Gemini, Grok and others.
There is nothing to install and nothing to sign up for.

The assistant reads the index, picks the one page that matches your problem, and answers out of it.

## Reading them yourself

Start at **[index.md](index.md)**.

Setting an event up for the first time: [set-up-an-event.md](set-up-an-event.md).

Not sure which app you are looking at: [the-three-apps.md](the-three-apps.md).

## If these pages do not answer it

Contact RFID Timing. A confident wrong answer during a race is worse than no answer, so the pages
tell an assistant to say when something is not covered rather than guess at it.
